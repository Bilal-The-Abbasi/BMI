# OwnerOS AI — Client Onboarding Checklist

Complete this checklist at the start of every new client engagement (any service tier).

---

## Pre-Kickoff (Before Day 1)

**OwnerOS AI Team:**
- [ ] Contract signed and filed
- [ ] Initial payment received and confirmed
- [ ] Project folder created: `/clients/[client-name]-[project-name]/`
- [ ] Client added to CRM at appropriate stage
- [ ] Project created in internal PM tool (ClickUp/Notion)
- [ ] Project tasks created and assigned (PM: [Founder 2 Name])
- [ ] Risk register opened and populated with initial risks
- [ ] Data Access Checklist sent to client
- [ ] AI Use Policy sent to client
- [ ] Client Responsibility Policy sent to client

**Client:**
- [ ] Policies reviewed and signed
- [ ] Primary point of contact designated and confirmed
- [ ] Data Access Checklist returned (or in progress)

---

## Kickoff Day

**OwnerOS AI sends:**
- [ ] Welcome email (see welcome-email.md)
- [ ] Intake questionnaire (or Audit intake form if Audit is the first step)
- [ ] Access request checklist (specific tool access needed)
- [ ] Kickoff call calendar invite

**OwnerOS AI team:**
- [ ] Internal kickoff meeting completed (both founders)
- [ ] Roles assigned: PM lead = [Founder 2]; Client communication lead = [Founder 1]
- [ ] Project timeline confirmed and shared with client

---

## Week 1

- [ ] All tool access granted (per Access Request Checklist)
- [ ] Intake questionnaire completed by client
- [ ] Discovery call completed (60 min)
- [ ] Call notes documented
- [ ] Tool inventory worksheet completed
- [ ] Lead flow worksheet completed
- [ ] Workflow mapping session scheduled

---

## Quality Gates Before Building

Before Phase 2 begins, confirm:
- [ ] Current state fully documented
- [ ] Score or assessment completed
- [ ] Client has approved the build plan / scope
- [ ] All tool access confirmed
- [ ] Timeline confirmed with client

---

## During Build

Weekly:
- [ ] Weekly update sent to client (see weekly-update-template.md)
- [ ] Any blockers escalated and resolved
- [ ] Client approvals received within 48 hours (or follow-up sent)

---

## Before Launch

- [ ] All deliverables built and tested
- [ ] QA checklist completed (see QA section)
- [ ] Human Review Checklist completed for all AI-generated content
- [ ] Training session scheduled
- [ ] Handoff document prepared (see handoff-document.md)

---

## Launch + Training

- [ ] Team training session completed (2 hours)
- [ ] Owner walkthrough completed (1 hour)
- [ ] Loom videos recorded and shared
- [ ] Quick-reference guides distributed to team
- [ ] 30-day check-in call scheduled
- [ ] All deliverables confirmed as accessible by client team

---

## Post-Launch

- [ ] Day 7: Quick check-in (email or 15-min call) — any issues?
- [ ] Day 30: 30-day review call (see 30-day post-launch review template)
- [ ] Case study opportunity assessed
- [ ] Testimonial request sent (if project went well)
- [ ] Retainer proposal sent (if applicable)
- [ ] Project closed in CRM and internal PM tool
