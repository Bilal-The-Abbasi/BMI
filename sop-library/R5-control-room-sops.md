# Room 5: The Control Room — Reporting and Visibility SOPs

---

## SOP R5-01: Owner Dashboard Review — Monday Morning

**Owner:** Business owner
**Trigger:** Every Monday morning, before the week begins
**Tools:** Dashboard (Looker Studio / Notion), CRM, Task board

### Steps
1. Open the owner dashboard (bookmark it — this should take under 10 minutes)
2. Review: Last week's lead count — up or down from previous week?
3. Review: Conversion rate — how many leads became appointments/clients?
4. Review: Open tasks — anything overdue from last week?
5. Review: Follow-up pipeline — any leads sitting at 5+ days without a response?
6. Review: Weekly Summary (filled out by front desk on Friday) — any issues flagged?
7. Decide: 1–2 owner actions to take today based on the review
8. Log: add a note to the Weekly Summary with any decisions made

### Quality Checklist
- [ ] Dashboard reviewed every Monday before 10 AM
- [ ] Key metrics checked: leads, conversions, tasks, follow-up pipeline
- [ ] Weekly Summary read
- [ ] At least 1 action item decided

### Escalation Rule
If the dashboard shows a significant issue (lead volume drop, conversion rate collapse, large number of overdue tasks) — investigate root cause before the end of Monday.

## SOP R5-02: AI Response Review

**Owner:** Designated staff reviewer
**Trigger:** Any AI-generated content is ready for use (emails, scripts, SOPs, summaries)
**Tools:** AI tool used, Human Review Checklist, Email/Notion

### Steps
1. Receive AI-drafted content for review
2. Open the Human Review Checklist (legal-templates/human-review-checklist.md)
3. Work through each section: accuracy, compliance, brand voice, sensitivity
4. If any issue is found — stop. Do not approve. Return to creator with specific notes
5. If all checks pass — approve and mark: "Reviewed by [name] — [date]"
6. File the approved version in the correct project folder
7. Log in Notion AI Prompt Library: "Prompt used — [date] — [outcome]"

### Quality Checklist
- [ ] Human Review Checklist completed
- [ ] No compliance issues found
- [ ] Approval logged with reviewer name and date

### Escalation Rule
Any content that cannot pass all review checks — escalate to both founders before using or sending.

## SOP R5-03: Quarterly Business Review (Internal)

**Owner:** Both founders
**Trigger:** Last week of each quarter (Q1: end of March, Q2: end of June, Q3: end of September, Q4: end of December)
**Tools:** Dashboard, CRM, Notion, Financial data

### Steps

**Preparation (1–2 days before):**
- Pull quarterly metrics: total leads, total clients, revenue, churn (retainer clients), net new projects
- Review client satisfaction: any complaints, testimonials, renewals
- Review internal operations: what worked, what didn't, what needs fixing

**Meeting agenda (1–2 hours):**
1. Revenue review — are we on track with annual goals?
2. Client review — current clients, health, renewal risk, expansion opportunities
3. Sales pipeline review — what's in the pipeline? What do we need to close?
4. Operations review — delivery quality, timeline compliance, PM issues
5. Marketing review — what's working? What lead sources are performing?
6. Team/capacity review — are we able to take on more clients?
7. Priorities for next quarter — top 3 focus areas

**After meeting:**
- Log quarterly review summary in Notion
- Update goals for next quarter
- Share key metrics with accountability partner or advisor if applicable

### Quality Checklist
- [ ] Meeting held within the last 2 weeks of the quarter
- [ ] All 7 agenda areas covered
- [ ] Next quarter priorities documented
- [ ] Summary logged

## SOP R5-04: Dashboard Review (Retainer Client)

**Owner:** OwnerOS AI delivery team (for retainer clients)
**Trigger:** Monthly retainer check-in (usually first week of each month)
**Tools:** Client dashboard, Weekly Summary log, CRM, Notion

### Steps
1. Pull last month's data from the client dashboard
2. Review: lead volume trends, conversion changes, follow-up performance, task completion
3. Identify: what improved vs. last month? What declined?
4. Identify: any new gaps or optimization opportunities?
5. Prepare the Monthly Retainer Report (see dashboard templates)
6. Use AI Summary Prompt to draft narrative section
7. Review AI draft for accuracy
8. Send to client before the monthly check-in call
9. On the call: walk through report, agree on 1–3 priorities for the next month

### Quality Checklist
- [ ] Report completed before monthly call
- [ ] AI narrative reviewed by human
- [ ] 1–3 priorities agreed and documented
- [ ] Action items assigned

## SOP R5-05: Change Request — OwnerOS AI Internal

**Owner:** PM (Founder 2)
**Trigger:** During a project, something needs to change from the original scope or plan
**Tools:** SOW, Email, Project board, CRM

### Steps
1. Identify the change: is it OwnerOS AI-initiated (we found a better way) or client-requested?
2. If OwnerOS AI-initiated: discuss with the other founder before presenting to client
3. Document the change: what's changing, why, and any impact on timeline or cost
4. If the change benefits the client and is within scope — implement and notify
5. If the change is out of scope and adds cost — follow SOP R4-03: Change Request Handling
6. Log the change in project notes

### Quality Checklist
- [ ] Change documented before implementation
- [ ] Both founders aligned on the decision
- [ ] Client notified appropriately
- [ ] Project notes updated
