## Notes for Delivery Team

- Send every [day] without fail — even if the only update is "we're in heads-down build mode this week"
- Never leave a "waiting on you" item without a specific date
- If something is delayed, say so clearly and explain why — don't wait to be asked
- Keep it scannable — use the exact format above
- If there's a critical decision the owner needs to make, use bold or a separate short paragraph
