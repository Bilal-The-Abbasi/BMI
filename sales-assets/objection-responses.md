# OwnerOS AI — Quick Objection Response Reference

*Condensed version for use during calls. Full detail in /brand/objection-handling.md*

---

| Objection | Quick Response |
|-----------|---------------|
| "We already use [HubSpot/GHL/ClickUp]" | "The tool isn't the issue — it's the process around it. We make the tools you have actually work." |
| "This sounds expensive" | "Compare to missed leads: if you lose one $2K job per week, that's $100K/year. The Audit will quantify your specific gap." |
| "We tried automation before and it didn't work" | "That's almost always because someone built a trigger/action without designing the process first. We map the process before we build anything." |
| "I don't have time for this right now" | "How much time are you spending on manual follow-up and answering the same questions? That's the time this buys back." |
| "We're a small team — is this overkill?" | "Small teams need this more. There's no margin for inefficiency when everyone is wearing 3 hats." |
| "Can't we just do this ourselves?" | "You can. But you won't — because running the business will win every time. We hold the project accountable." |
| "AI isn't right for us" | "That's fair. The SOPs, dashboards, and workflows work without AI too. AI just makes certain parts faster." |
| "We need to think about it" | "What specifically are you still unsure about? I'd rather address it now than send an email into the void." |
| "We already have an ops manager" | "We build what they use. SOPs, automations, dashboards — it makes their job better, not redundant." |
| "What if we don't stick with it?" | "We design for adoption. Training is built in. SOPs make it repeatable. We're here for 30 days post-launch." |
