## SOP G-01: Refund Request

**Owner:** Manager / Owner
**Trigger:** Customer requests a refund for a service
**Tools:** Accounting software, Email, CRM

### Steps
1. Acknowledge the request warmly and without committing to anything:
   > "Thank you for reaching out. I want to make sure we understand your situation — can you share a bit more about what happened?"
2. Log the request in CRM: date, customer, service, reason stated
3. Escalate to manager or owner — do not make refund decisions unilaterally
4. Owner reviews against refund policy (see current policy document)
5. If refund is approved: process within 3–5 business days and notify the customer
6. If refund is denied: explain the policy professionally and offer an alternative (credit, redo, etc.)
7. Follow up to confirm the resolution was acceptable

### Quality Checklist
- [ ] Request acknowledged within 24 hours
- [ ] Escalated to manager before decision
- [ ] Decision communicated within 48 hours
- [ ] Outcome logged in CRM

### Escalation Rule
Any refund over $[threshold] or any threat of dispute/chargeback requires owner decision and possible legal review before responding.

## SOP G-02: Referral Request (Asking for Referrals)

**Owner:** Front desk / Account manager
**Trigger:** Service is completed and customer expresses satisfaction
**Tools:** Email, SMS, Referral tracking in CRM

### Steps
1. Timing: when the customer expresses a compliment, satisfaction, or positive outcome — that's the moment
2. Use the Referral Request Template:
   > "I'm so glad you're happy with the results. If you know anyone else who could benefit from what we do, we'd love an introduction. We treat every referral with the same care we gave you."
3. Optionally explain the referral benefit (if a referral program is in place): "We [offer X] for anyone who sends us a client who moves forward."
4. Log in CRM: "Referral request made — [date] — [customer]"
5. If the customer later provides a referral, send a thank-you same day

### Quality Checklist
- [ ] Ask made at the right moment (not too early, not too transactional)
- [ ] CRM logged
- [ ] Referral source tracked if/when referral is received

## SOP G-03: Password and Access Management

**Owner:** Operations manager
**Trigger:** New employee joins; employee leaves; tool is added or removed; quarterly audit
**Tools:** Password manager (1Password, LastPass, or Bitwarden), Access list

### Steps

**When adding a new employee:**
1. Create their account in the password manager
2. Share only the access relevant to their role (not all accounts)
3. Set up 2FA for any sensitive accounts
4. Log in the Access Register: employee name, accounts granted, date

**When an employee leaves:**
1. Within 24 hours of departure: remove from all shared accounts
2. Reset passwords for any accounts they had full access to
3. Revoke 2FA if they had it
4. Log changes in Access Register

**Quarterly audit:**
1. Review Access Register — does everyone have appropriate access?
2. Remove access for anyone no longer in that role
3. Identify any shared passwords that should be individualized

### Quality Checklist
- [ ] Access granted only to what's needed for the role
- [ ] 2FA enabled on sensitive accounts
- [ ] Access removed within 24 hours of departure
- [ ] Quarterly audit completed

### Escalation Rule
If unauthorized access is suspected — notify owner immediately and change all affected passwords within the hour.

## SOP G-04: Service Completion Follow-Up

**Owner:** Front desk / Account manager
**Trigger:** Service or project is completed and delivered to the customer
**Tools:** Email, SMS, CRM

### Steps
1. Send service completion message within 24 hours:
   > "Thank you for choosing us for [service]. We hope you're happy with the results! If you have any questions in the next few days, just reach out."
2. Schedule a 7-day check-in (automated or manual):
   > "Just checking in — how has [service/result] been working out? Any questions?"
3. At 7-day check-in, if positive: send review request (SOP R2-07)
4. If any issue mentioned at 7-day: log in CRM and follow up until resolved
5. At 30 days: add to re-engagement list if applicable (new services, seasonal, etc.)

### Quality Checklist
- [ ] Completion message sent within 24 hours
- [ ] 7-day check-in scheduled or automated
- [ ] Review request sent at appropriate time
- [ ] Any issues flagged and followed up

## SOP G-05: Project Kickoff

**Owner:** PM (Founder 2)
**Trigger:** New implementation project begins (QuickStart, Growth System, or Full Buildout)
**Tools:** Project management tool, Email, Notion, CRM

### Steps
1. Create project in PM tool (ClickUp/Notion) with:
   - Project name
   - Start date / target completion
   - Scope reference (link to SOW)
   - Team assignments
   - Client contact
2. Set up the Command Center workspace in Notion for this client
3. Send welcome email and intake documents within 24 hours of contract signing
4. Schedule kickoff call within 5 business days
5. On kickoff call: review scope, timeline, roles, access requirements, communication cadence
6. After kickoff call: send follow-up email with call summary and first action items

### Quality Checklist
- [ ] Project created in PM tool
- [ ] Command Center set up
- [ ] Welcome email sent within 24 hours
- [ ] Kickoff call scheduled
- [ ] Post-kickoff summary sent

### Escalation Rule
If kickoff call reveals scope misalignment — pause project and discuss with both founders before proceeding.
