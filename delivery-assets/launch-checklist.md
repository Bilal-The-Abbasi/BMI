# OwnerOS AI — Launch Checklist

Complete before handing off to the client.

---

## Pre-Launch QA

### Front Door (if built)
- [ ] Lead intake form live and submitting correctly
- [ ] Form submissions routing to CRM correctly
- [ ] Source tracking parameters working
- [ ] Missed call automation tested with real number
- [ ] Initial response template reviewed for accuracy and tone
- [ ] Response sent within target time in testing (under 5 minutes)

### Follow-Up Desk (if built)
- [ ] Follow-up sequence enrolled and tested with a test contact
- [ ] All sequence messages reviewed for accuracy — no false claims, no price guarantees
- [ ] Appointment reminders triggering at correct intervals
- [ ] Quote follow-up automation working
- [ ] Unsubscribe / opt-out mechanism working (TCPA/CAN-SPAM compliance)

### Playbook (if built)
- [ ] All SOPs reviewed for accuracy by client
- [ ] FAQ knowledge base reviewed and approved
- [ ] Brand voice guide signed off by owner
- [ ] All Notion/ClickUp/tool links working
- [ ] Permissions set correctly (right people have access, wrong people don't)

### Workroom (if built)
- [ ] Task board configured with correct team members
- [ ] Recurring checklists set up and tested (first instance created)
- [ ] Team responsibilities documented and accessible
- [ ] Owner approval queue tested

### Control Room (if built)
- [ ] Owner dashboard live and displaying accurate data
- [ ] Weekly summary template in place
- [ ] Dashboard reviewed by owner — metrics make sense
- [ ] Data sources confirmed as accurate
