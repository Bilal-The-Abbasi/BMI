## Pricing Detail

### OwnerOS Audit — $1,500 flat

Always flat rate. No negotiation below $1,200 (absolute floor).

Includes:
- Intake questionnaire
- 60-minute discovery session
- OwnerOS Readiness Score
- 5 Rooms Assessment
- Visual workflow map
- Bottleneck report
- Quick wins list
- 90-day roadmap
- 12–15 page PDF report
- 30-minute presentation call

**Note:** $1,500 is credited toward any subsequent implementation project if the client signs within 60 days of audit delivery.

---

### OwnerOS QuickStart — $5,000 flat

One Room, fully implemented. Client selects from:

| Option | What's Built |
|--------|-------------|
| Lead Follow-Up System | Lead intake, instant response, 5-step follow-up sequence, lead tracking |
| AI Office Assistant | FAQ bot, intake assistant, response templates, escalation rules |
| SOP Starter Library | 5–8 core SOPs, FAQ knowledge base, brand voice guide, training guide |
| Owner Dashboard | KPI dashboard, weekly summary template, AI reporting prompts |
| Client Intake System | Intake form, onboarding checklist, welcome email, intake SOP |
| Content Workflow System | Content request, approval, publishing workflow |
| Proposal Follow-Up System | Estimate tracker, follow-up sequence, win/loss tracking |

Pricing range:
- Simple tool setup with SOPs: $4,500
- Complex automation with training: $5,500
- Default flat rate: $5,000

---

### OwnerOS Growth System — $10,000–$15,000

Pricing factors:
- Number of employees trained (more staff = higher)
- Number of tools being integrated
- Complexity of existing workflows
- Whether Audit was purchased (credit $1,500)

| Scope | Price |
|-------|-------|
| 1–10 employees, 3–4 tools | $10,000 |
| 10–20 employees, 4–6 tools | $12,500 |
| 20–30 employees, 5+ tools | $15,000 |

---

### OwnerOS Full Buildout — $25,000–$50,000

Custom-quoted. Requires a scoping call with both founders.

Factors:
- Number of departments mapped
- Number of employees
- Tool complexity and integrations
- Training scope (staff + management)
- Number of SOPs (20–30)

## Discounting Policy

- We do not discount standard rates
- If budget is a constraint, we scope down (e.g., QuickStart instead of Growth System) rather than discount
- Beta/case study discount for first 3 clients: 25% off implementation, full Audit price

**Do not offer discounts on discovery calls. Bring a scope-down option if budget is the objection.**
