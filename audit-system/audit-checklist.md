# OwnerOS AI — Audit Project Checklist

Use this to track every step of the Audit engagement from sale to report delivery.

---

## Pre-Audit (Before Work Begins)

- [ ] Proposal accepted / contract signed
- [ ] Invoice sent and initial payment received
- [ ] Intake form link sent to client (with deadline: within 3 business days)
- [ ] Discovery call scheduled on calendar
- [ ] Audit project folder created in internal project tool
- [ ] Client added to CRM at "Audit — In Progress" stage

---

## Intake Review (Before Discovery Call)

- [ ] Intake form completed by client
- [ ] Intake form reviewed by OwnerOS AI team
- [ ] Key themes and hypotheses noted
- [ ] Discovery call questions selected and ordered
- [ ] Scoring rubric printed / opened for use during call

---

## Discovery Call

- [ ] All questions covered (use Interview Questions doc)
- [ ] Call recorded (with client permission)
- [ ] Notes captured in call notes template
- [ ] Tool stack confirmed
- [ ] Hypothesis scores updated based on conversation
- [ ] Any follow-up information requested from client

---

## Report Build (5–7 Business Days)

- [ ] All 10 dimensions scored using rubric
- [ ] Score notes completed for each dimension
- [ ] 5 Rooms assessment written (current state, impact, quick wins)
- [ ] Tool stack review completed
- [ ] Top 3 bottlenecks identified and written
- [ ] Quick wins list (minimum 5 items) completed
- [ ] 90-day roadmap filled in
- [ ] Recommended next step written with pricing
- [ ] Report formatted in branded PDF template
- [ ] AI-drafted content reviewed by team member for accuracy
- [ ] Report reviewed by second team member (quality check)
- [ ] Report stored in client project folder

---

## Report Presentation

- [ ] Presentation call scheduled (30 minutes)
- [ ] Report sent to client 24 hours before the call
- [ ] Upsell script reviewed (audit-to-build-upsell.md)
- [ ] Presentation completed
- [ ] Client questions answered
- [ ] Next step discussed and agreed (or follow-up agreed)
- [ ] CRM stage updated

---

## Post-Presentation Follow-Up

- [ ] Follow-up email sent within 2 hours (Template 6 in follow-up-email-templates.md)
- [ ] SOW sent if client wants to move forward
- [ ] Follow-up call scheduled if needed (3 days after presentation)
- [ ] Case study opportunity noted if applicable
- [ ] Client added to nurture sequence if not ready to move forward

---

## Quality Checklist for Report

Before sending, confirm:

- [ ] Business name correct throughout report
- [ ] Score totals add up correctly
- [ ] No lorem ipsum or placeholder text remaining
- [ ] All specific claims are based on intake + call data (not invented)
- [ ] No medical, legal, or financial advice given
- [ ] No ROI guarantees stated
- [ ] Disclaimer included at report footer
- [ ] Recommended next step pricing is current
- [ ] PDF is properly formatted and readable on mobile
